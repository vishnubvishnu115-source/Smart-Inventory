When an item's remaining inventory reaches or drops below its defined par reorder level, SmartStock automatically drafts an itemized purchase order email with the supplier's contact address, suggested reorder quantity, and delivery instructions. You can review the draft or have it delivered automatically via Zoho Catalyst Mail.
All user credentials use salted PBKDF2 SHA-256 cryptographic hashing stored directly in the Zoho Catalyst Data Store Users table. Passwords are never stored or transmitted in plaintext.
Yes. SmartStock includes built-in Role-Based Access Control (RBAC). Operators can scan barcodes and record sales; Managers can approve purchase orders and restock items; Administrators have full control over catalog SKUs, user accounts, and system configuration.
SmartStock is 100% serverless. The frontend is hosted on Catalyst Slate edge CDN with zero build overhead, while the API runs on Node.js Advanced I/O functions backed by ACID-compliant Catalyst Data Store relational tables.
